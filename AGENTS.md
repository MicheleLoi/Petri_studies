# Petri_studies assistant guidance

Use Giano T for current project tracing. Open this repository root as the
tracked folder and invoke the `giano-tracing` plugin in a local assistant task.
The assistant may create proposals under `proposte/`; only the human acts on
them in Giano, and only Giano writes its register or contacts its notary.

Preserve `lab_journal.md` as append-only. Preserve Git history, evals,
preregistrations, configurations, archives and historical governance records.
Do not assign an old evaluation to the currently open Giano session. Do not
start, simulate or call the retired MHC harness from this repository.

The change of tracing infrastructure does not authorize changes to the
experimental target, auditor or judge models. Never perform a live model/API
run without the user's instruction; use dry-run and local tests for maintenance.
