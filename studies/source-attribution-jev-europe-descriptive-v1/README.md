# Jev European source-attribution supplement

Prospective supplement: **288 new slots**, 16 blocks, German debt-brake and Swiss nuclear-policy arguments. The [protocol](PROTOCOLLO.md) fixes the comparisons and limits. Exact texts, attributed organizations, Jev rubric, payloads and order are in `materials/` and `plan.json`. [Model identification](MODEL_IDENTITY.md) distinguishes the gateway alias from the presumed model version.

The two earlier studies are preserved. Their observations were already known when this supplement was planned. This collection adds Jev to the two European cases; it neither reruns the US sample nor retroactively extends an earlier registration. No anonymous baseline, alternative rubric, inference test or outcome-dependent sampling rule is added.

`code/` contains the collector, parser, descriptive report and offline checks. `verification/` contains synthetic checks only. `ENVIRONMENT.json` records the tested Python dependencies. `MANIFEST.json` identifies exact file bytes with SHA256 and excludes its own hash. Payload hashing uses UTF-8 JSON, sorted keys, compact separators, unescaped Unicode and no non-finite numbers. These hashes do not require Giano code and do not establish external notarization.

The package must be published and anonymous access verified before its first scientific request. A genuine private launch record must link its manifest to that publication. Creating this folder does not establish publication. Do not modify a frozen package in place.

No credentials, conversations, private session identifiers, raw scientific responses or empirical results are included. Data and reports remain private pending separate publication authorization. Use [OPERATIONS.md](OPERATIONS.md) for execution and reporting. A GitHub release provides a dated public deposit, without a claim of immutable third-party registration.
